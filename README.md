# 架构师刷题台 · 软考练习与模拟考

以「系统架构设计师（高级）」为首发科目的刷题与真题模考平台。按《软考平台调研与实施方案》落地：
**章节练习 + 真题模考 + 错题本** 三件套打穿综合知识（75 题答对 45 题即过线），案例分析支持逐问作答与自评，
模考严格仿真机考规则（连考计时、答题卡、标记、断点续考）。

## 快速开始

```bash
pnpm install        # 或 npm install
pnpm dev            # http://localhost:5173
```

### MySQL 数据库（本地）

学习记录（作答统计/错题本/模考进度/每日活跃/案例自评）可落 MySQL，本地试用：

```bash
docker compose up -d   # 起 MySQL（本机已有 MySQL 8 可跳过这步）
npm run db:seed        # 建库建表 + 导入题库（幂等）
npm run dev:all        # 同时起 API(:8787) 与前端(:5173)
```

- 服务端（`server/`，Express + mysql2）：`GET /api/health|bank|state` + `POST /api/actions`，
  动作语义与 `src/lib/store.ts` 本地逻辑一一对应（含错题本 1/3/7 天顺延）。
- 前端启动时探测 `/api`：可达即切 **MySQL 模式**（侧栏徽标点亮，启动用服务端状态水合，
  之后每个动作本地即时生效并微批推送落库）；不可达自动回退 localStorage，数据不丢。
- 连接参数走环境变量 `DB_HOST/DB_PORT/DB_USER/DB_PASS/DB_NAME`，默认 `127.0.0.1:3306`，
  root 空密码，库 `ruankao`（首次访问需先 `npm run db:seed` 建库）。

克隆后自带**示例题库**（`src/data/bank.sample.json`，12 道自创题 + 1 案例 + 1 示例卷），开箱即可跑通练习/模考/错题本全流程。正式题库 `src/data/bank.json` 因版权归属不入仓库：把自有资料 DOC 放入资料目录后运行管线生成：

```bash
RK_SRC_ROOT="/你的资料目录/7、模拟题" pnpm bank:parse
# macOS：textutil 提取 DOC → 结构化 JSON + 质检报告（bank-report.json 只留本地，不入仓库）
```

## 题库版权策略

- **代码开源（MIT），题库数据不随仓库分发**。`src/data/bank.json` 已加入 `.gitignore`——题目内容来自个人解析的第三方资料，版权归属原作者，请自行获取并使用自有资料生成。
- 仓库内置的 `bank.sample.json` 全部为**自创演示题**，可自由使用与修改，用于开发、演示与 CI。
- 如果你拥有题目内容的合法授权或自创了题库，欢迎通过 PR 讨论数据格式的改进，但请勿向仓库提交无授权的第三方题目。

## 功能地图

| 模块 | 说明 |
|---|---|
| 今日 | 总正确率 vs 60% 目标环、断点续考入口、到期错题提醒、近 14 天活跃 |
| 章节练习 | 12 章知识树 + 综合桶；即答即判；只做未做 / 只做错题；单选 + 组合填空 |
| 真题模考 | 整卷连续计时、答题卡三态（已答/未答/标记）跳题、交卷二次确认、到点自动交卷、**断点续考**（进度每 5 秒落盘）、成绩单 + 逐题复盘 |
| 错题本 | 答错自动归档；错因标记（知识/审题/计算）；**1/3/7 天间隔重现**，重练答对移出 |
| 案例分析 | 真实大题逐问作答（草稿自动保存）→ 对照参考答案 → 给分点三档自评 |
| 统计 | 知识域掌握度（45/60 双参考线）、模考历史、触达覆盖率、30 天活跃 |

## 目录结构

```

src/lib/api.ts             MySQL 后端客户端：探测/水合/动作微批推送
server/                    本地 API（Express + mysql2）：schema、种子、动作落库
src/components/            题卡（练习/模考/复盘三形态）、答题卡、目标环、掌握度条
src/views/                 六个页面的视图组件
```

## 数据来源与可信度

- **综合知识 262 题**：来自资料夹「7、模拟题」4 份 DOC 卷的自动解析，`sourceRef` 标注出处卷名；
  图表依赖题（DOC 转文本后图片丢失）已在管线中剔除，答案与解析逐题对齐校验。
- **真题（回忆版）10 题**：来自交付物原型的人工校对数据（2025 上半年）。
- **章节练习 4 题**：原型自带（第 4 章节选，含组合填空题型）。
- **案例 16 例**：「案例分析模拟题」DOC 解析所得，图片依赖的例题已剔除。
- 章节归类中标注「自动归类」的题目来自关键词分类器，属初始归类，可在后台修正（二期做管理后台）。

机考后官方不再公布原卷，回忆版题目以社区校对为准——这也是 `source` / `confidence` 字段存在的意义。

## 判分与组卷规则（实施方案 §06）

- 客观题判分是纯函数（`src/lib/grading.ts`）；`combo_blank` 组合填空**全部空对才得分**。
- 组卷：真题/模拟整卷直取（`papers`）；章节练习按知识域过滤抽样（后续接入难度加权）。
- 45 分及格线换算：所有进度指标以「正确率 ≥60%」为北极星展示。
